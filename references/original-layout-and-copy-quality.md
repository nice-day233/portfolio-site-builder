# 原创排版与文案质量规则

## 使用边界

仅当参考网站的排版与用户素材存在明确冲突时读取：

- 参考站主要是横版图片或视频，用户素材主要是竖版。
- 参考站每组媒体很少，用户同一项目有多图或多视频。
- 套用参考比例会裁掉人物、产品、文字或关键构图。
- 参考区块的信息密度无法承接用户实际文案。
- 用户素材混合横版、竖版、方图、截图和视频，单一组件无法安全承接。

不满足条件时，不读取本文件。即使触发，也只重排冲突章节；颜色、字体气质、圆角、阴影、边框和动效仍继承参考站。

## 调用记录

```text
章节名称
参考媒体数量与比例
用户素材数量与比例
直接套用的问题
保留的参考规则
原创布局
```

不得用“更好看”或“更有创意”作为触发理由。

## 布局选择

- 单张横版媒体：大幅横向展示。
- 单张竖版媒体：竖版卡片，可与说明、数据或辅助素材并列。
- 多张竖版图片：2–4 列网格，移动端为 1–2 列。
- 多条竖版视频：统一高度的 reel 卡片组。
- 横竖混合：主次拼贴、分组画廊或分别成行，不强制统一裁切。
- 大量同类素材：精选展示，其余分组或可展开，避免无限拉长页面。
- 账号截图与数据：并列展示，数据必须与项目有来源关系。

优先保护主体和作品文字。必须裁切时分别设置断点焦点；低分辨率媒体不放大为整屏主视觉。

## 文字层级

1. 一级标题：页面核心信息和视觉焦点。
2. 二级标题：章节与内容分区。
3. 三级标题：项目、步骤或小节。
4. 正文：详细说明。
5. 辅助信息：角色、时间、类型、图注。

同级文字必须使用一致的字体、字号、字重、行高、字距和间距。

### 行距与字距起始值

- 大型标题：`1.0–1.15`
- 二级标题：`1.1–1.25`
- 三级标题：`1.2–1.35`
- 中文正文：`1.4–1.6`，长文可到 `1.7–1.8`
- 辅助文字：`1.4–1.6`
- 中文正文字距：`0–0.02em`
- 标题字距：`-0.02em–0.01em`
- `0.05em` 左右只用于短标题、英文辅助标题或装饰文字

这些是原创重排的起始区间，不覆盖参考站中已经安全可读的成熟排版。

## 留白与密度

- 先定义区块上下留白、元素间距和媒体网格间距 token。
- 同级章节的顶部与底部留白保持一致，特殊调整必须有内容理由。
- 多媒体区块外部留白应清晰界定章节，不小于媒体内部的视觉安全距离。
- 不使用空容器、固定超大高度、无意义占位或过大的 `min-height` 制造空白。
- 媒体之间必须有稳定间距或明确分隔。
- 相邻章节的密度平滑变化，不从极度拥挤突然跳到整屏空白。

以下属于大幅空白问题：

- 普通内容章节连续空白接近一个视口且没有功能。
- 内容结束后保留明显大于同级章节的底部空白。
- 固定网格高度在最后一行后产生大块空区。
- 竖版素材放入横版框后形成无设计意图的大面积空带。

以下属于视觉拥挤：

- 媒体、标题、正文和标签的所属层级不清。
- 卡片间距小于卡片内部文字与边缘的安全距离。
- 多个视频控制栏、说明和标签相互争抢。
- 同屏出现过多同权重大图、大标题或强调色。
- 为塞入内容而使用过小字号或过紧行距。

修复顺序：删除无意义固定高度 → 调整列数与比例 → 分组混合素材 → 统一 padding 与 gap → 精简文案 → 最后微调字号或尺寸。

## 标题语义换行

一级、二级和三级标题必须以完整语义单位换行。优先在主语或主题之后、动宾结构完成后、并列短语之间或中英文自然切换处换行。

禁止拆开品牌名、英文单词、固定词组和数字单位；禁止介词、连词、助词或标点孤立；禁止单个汉字或两个无完整语义的汉字成为尾行。

换行不通顺时依次：重写标题 → 调整容器宽度 → 按语义块控制断行 → 微调字号与字距。不得只靠缩小字号硬塞。

## 正文尾行

所有中文正文在规定断点下，最后一行至少包含 3 个中文字符。按钮、标签、英文辅助标题、数字、日期和图注不适用此规则。

不足时依次：改写句子 → 调整词序 → 使用等义短表达 → 调整容器宽度 → 微调字号或字距 → 最后使用有语义依据的人工换行。

禁止添加无意义文字、不可见字符或连续空格。

## 防重叠与防裁切

- 所有文字零重叠，不被媒体、按钮、导航或装饰覆盖。
- 不用负 margin、过量 transform 或绝对定位修复普通文本流。
- 文本容器优先内容自适应高度。
- 不对有效标题和正文使用会隐藏文字的 `overflow: hidden`。
- 字体加载前后都要检查最终换行和高度。
- 动画初始态、结束态和减少动态模式都必须可读。
- 固定导航不得遮挡锚点标题。

## 专项质量检查

至少检查桌面 `1440/1280px`、平板 `768px`、手机 `390/375px`。

顺序：

1. 从顶部到底部检查章节节奏。
2. 检查多媒体章节的上下留白、卡片间距和最后一行网格。
3. 检查所有标题的语义换行。
4. 检查所有中文正文尾行。
5. 检查文字之间、文字与媒体、导航与锚点之间的重叠。
6. 字体加载完成后复查。
7. 检查横竖素材的裁切、变形和空带。
8. 检查移动端的过长空白和过密堆叠。
9. 检查减少动态模式。

任何文字重叠或裁切、正文尾行不足、标题语义断裂、无功能大幅空白、媒体拥挤、媒体变形或同级留白无规则都属于阻断性问题。

每次修复后重新渲染受影响断点和相邻章节。完成条件是阻断性问题为零。连续三轮仍无法解决时，保留最好版本并报告具体冲突。
