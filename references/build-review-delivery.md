# 网站构建、检查与交付

## 构建要求

- 默认生成响应式静态网站。
- 首页为 `index.html`。
- 图片、视频、字体和脚本使用可用的相对路径。
- 使用真实素材，不用虚构图片替换用户已有作品。
- 视频可点击播放；同时播放多个视频时应避免声音和控制冲突。
- 交互简洁，不妨碍阅读。
- 所有页面共用同一设计系统。
- 支持 `prefers-reduced-motion`。
- 语义结构、键盘焦点、图片替代文字和按钮标签应可用。

## 版本管理

- 第一版使用 `作品集网站_V1` 或用户指定名称。
- 更换参考网站、页面结构或整体风格时创建下一版本。
- 小范围文案和素材修改可以更新当前版本。
- 不覆盖仍有价值的旧版本。
- 每个版本使用独立目录，首页统一为 `index.html`。

## 文件检查

- `index.html` 存在并能打开。
- CSS、脚本、图片、视频和字体路径有效。
- 页面锚点和导航有效。
- 没有空白默认页、损坏媒体或无意义占位。
- 旧版本按要求保留。

## 参考还原检查

- 页面章节和首屏构图符合既定映射。
- 页面宽度、网格、边距和对齐关系一致。
- 标题、正文、注释的层级比例一致。
- 色彩面积、圆角、边框、阴影和留白节奏一致。
- 图片比例、裁切、按钮、标签和交互有参考依据。
- 移动端重排逻辑仍保持同一设计语言。
- 没有混入参考网站之外的第二套风格。

## 响应式检查

至少检查：

- 桌面：`1440px` 或 `1280px`
- 平板：`768px`
- 手机：`390px` 或 `375px`

逐断点检查：

- 导航和按钮是否可操作。
- 标题是否语义顺畅、无孤立字词。
- 正文是否被裁切、重叠或出现不足 3 个中文字符的尾行。
- 数字和单位是否分开。
- 图片和视频是否变形或错误裁切。
- 多媒体网格是否形成大幅空白或视觉拥挤。
- 固定导航是否遮挡锚点标题。

## 多媒体检查

- 同级章节的上下留白遵循同一 token。
- 多图、多视频区块的外部留白不小于卡片内部的视觉安全距离。
- 最后一行网格不因固定高度留下大块空白。
- 不使用空容器、超大 `min-height` 或无意义占位制造留白。
- 媒体之间有清晰间距，单个作品可以被识别。
- 横竖混合素材不被统一拉伸或强制裁成同一比例。

## 文字检查

- 每页最多一个一级标题。
- 同级标题样式一致。
- 标题按照语义语法换行。
- 所有可见文字零重叠、零裁切。
- 中文正文最后一行不少于 3 个中文字符。
- 注释不小于 `12px`。
- 字体加载完成后重新确认换行与容器高度。

## 交互检查

- 导航当前状态正确。
- 按钮、灯箱、播放器和关闭操作可用。
- 键盘焦点可见。
- 动画不会阻止内容显示。
- 减少动态模式下内容直接可读。
- 页面无明显脚本错误。

## 阻断性问题

存在以下任一情况不得交付：

- 页面或关键资源无法打开。
- 文字重叠、裁切或不可读。
- 标题语义断裂。
- 中文正文尾行不足 3 个中文字符。
- 普通章节出现无功能的大幅空白。
- 多媒体区块明显拥挤。
- 媒体变形或关键主体被错误裁切。
- 桌面、平板或手机任一主要断点不可用。

修复后重新检查受影响断点和相邻章节。若三轮修复后仍存在参考结构与素材之间的客观冲突，保留当前最好版本，并明确报告冲突，不得声称检查通过。

## 交付内容

- 最新版本入口
- 上一版本入口（如有）
- 当前版本名称
- 已接入素材概况
- 待确认或占位信息
- 参考还原、响应式和文字检查的简短结果

回复保持简洁，让网站文件本身承担主要信息。
