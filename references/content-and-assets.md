# 内容、证据与素材处理

## 来源台账

读取输入后，为重要内容标记来源等级：

- `F`：用户文件或消息中的明确事实，可以直接陈述。
- `A`：素材本身能够证明的内容，例如画幅、主题、作品类型和视觉元素。
- `I`：根据事实与素材做出的安全推导，只能作为概括。
- `P`：缺少依据的占位或创作性补充，必须删除、标注或请用户确认。

使用字段：

```text
内容项｜最终表达｜来源等级｜来源位置｜允许改写范围｜是否需要确认
```

数字成果、品牌合作、任职关系、奖项、客户名和时间只能来自 `F`。文件名可以辅助归类，但不能单独证明商业关系、个人职责或成果。

## 自动提取

优先从现有资料中提取：

- 姓名或署名
- 目标岗位和职业阶段
- 城市、求职或合作状态
- 专业方向和工具技能
- 教育与工作经历
- 项目、职责、方法和成果数据
- 联系方式
- 图片、视频、截图和设计文件

不得重复询问已经明确提供的信息。

## 表格与文档读取

- 先检查合并单元格、空白续行、隐藏信息和多段文本。
- 项目名为空但描述非空的行，优先判断是否属于上一项目。
- 不自动补造缺失月份、年份、客户或职责。
- 同一项目的多段描述应合并或明确拆成子作品，不能静默丢失。
- 原文只有“自行设计”等信息时，可以根据职责和素材写中性描述，但不能补结果。

## 项目实体

写页面前先建立：

```text
项目名称
项目类型
时间
职责
原始事实
原始描述
子作品
图片
视频
公开数据
内容缺口
证据等级
```

合并与扩展规则：

1. 同名或明显属于同一主题的续行合并。
2. 表格有项目、文案不足时，使用素材和职责补充“做了什么”的中性描述。
3. 素材组明显形成独立作品、但履历中没有对应项目时，可以创建“素材驱动项目”，标为 `A/I`。
4. 素材驱动项目不得声称客户关系、发布时间、业务成果或职责范围。
5. 横版视频、竖版视频、海报、摄影和截图分别选择合适展示组件。

## 素材盘点

至少记录：

- 文件名和类型
- 尺寸、画幅和时长
- 可能所属项目
- 是否适合作封面或详情
- 是否存在重复、低清、损坏或无法打开
- 是否需要用户确认

先盘点再使用。无法判断归属的素材进入待确认清单，快速模式下可以暂不使用，不阻止首版生成。

## 素材整理授权

未经用户明确同意，不得移动、重命名、覆盖或删除原始素材。

用户同意整理后，默认建立副本：

```text
已整理_作品集素材
├── 01_个人资料
├── 02_项目素材
├── 03_视频作品
├── 04_文案与简历
└── 99_待确认
```

项目较多时，在 `02_项目素材` 下继续按项目分组。默认保留原文件，统一命名只作用于整理副本。

## 项目与素材对应表

```text
项目名称：
项目类型：
项目封面：
详情图片：
项目视频：
个人职责：
展示位置：
素材状态：可用 / 待确认 / 暂不使用
来源等级：F / A / I / P
```

完整模式下请用户确认对应关系后再生成。快速模式可以自动使用高置信度素材，把低置信度内容列入待确认。

## 内容模块

作品集信息通常覆盖：

- 封面与职业定位
- 个人介绍与专业能力
- 工作理念或工作方法
- 数据成果与能力证明
- 项目经验与工作流程
- 联系方式与结束邀约

这些是内容覆盖范围，不是固定页面顺序。最终章节顺序优先服从参考网站和用户要求。
