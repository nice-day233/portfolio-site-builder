# Nice × Gradia 案例参考

## 使用场景

当输入是稀疏经历表、参考站不是作品集、同时存在多类真实图片和视频时读取。本案例用于学习决策方法，不用于复制具体颜色、文案、项目数量或页面顺序。

## 输入特征

经历表只有四个项目，其中两个只有项目名和职责，一个项目包含空白项目名的续行描述，一个项目包含可验证成果数据。最终网站还使用了个人照片、香氛图、电商海报、账号截图和多条视频。

因此正确模型不是“Excel 转网页”，而是：

```text
Excel 建立项目骨架
真实素材补充展示证据
参考网站提供设计语法
来源台账控制事实边界
```

## 关键方法

### 1. 来源分层

- 表格中的项目、职责、时间和成果为事实。
- 图片和视频证明作品类型与视觉内容。
- 从素材形成的新项目属于素材驱动项目，不自动成为履历事实。
- 文件名、职业标题和个人介绍属于推导或待确认。

### 2. 续行归并

项目名为空但文案非空的行，应优先归并到上一项目或拆成子作品，不能丢失。

### 3. 不补造日期

输入为 `2024–2025.12` 时，不补成 `2024.01–2025.12`。缺失月份保持原样或请用户确认。

### 4. 参考站映射

Gradia 的常见区块可映射为：

| 参考区块 | 作品集承接 |
|---|---|
| 浮层导航 | 关于、作品、经历、联系 |
| Hero | 职业定位、查看作品、联系入口 |
| Services | 专业能力或项目类别 |
| Showcase / 视觉长廊 | 项目画廊和视频 |
| About / Mission | 个人介绍和工作理念 |
| Features / Steps | 能力、工作路径或方法 |
| Footer | 署名、导航和返回入口 |

价格、客户评价和 FAQ 没有真实内容承接时省略。

### 5. 素材决定组件

- 香氛系列图 → 主次画廊
- 竖版电商海报 → 多列网格
- 横版概念片 → 大幅播放器
- 账号截图与成果 → 截图加指标卡
- 多条竖版带货视频 → reel 卡片组

### 6. 视觉语法迁移

案例迁移的是浅色背景、柔和渐变、胶囊导航、圆角卡片、清晰媒体展示和轻动效等设计关系。具体色值和尺寸只属于该案例，不是 Skill 默认值。

## 案例暴露的风险

- 职业标题、署名和个人介绍可能被当成事实直接使用。
- 缺失月份可能被自动补齐。
- 空白项目名的续行文案可能丢失。
- 素材驱动项目可能被误写为正式履历。
- 页面内计算出的“项目类别数量”可能被误当成外部业绩。
- “严格参考”可能被误解为逐区块机械复制。
